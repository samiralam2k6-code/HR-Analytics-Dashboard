## HR Analytics Dashboard – Power BI

This project focuses on analyzing Human Resources (HR) data using Microsoft Power BI to gain meaningful insights into employee demographics, workforce distribution, attrition, and overall employee performance.

The dashboard transforms raw HR data into interactive visualizations and key performance indicators (KPIs), helping users understand workforce trends and support data-driven HR decision-making.

### Key Features
- Employee Headcount Analysis
- Employee Attrition Analysis
- Department-wise Workforce Distribution
- Gender and Age Group Analysis
- Job Role and Salary Analysis
- Interactive Charts, Filters, and KPIs

### Tools & Technologies
- Microsoft Power BI
- Power Query for Data Cleaning and Transformation
- DAX for Measures and Calculations (if used)

### Project Objective
To provide actionable HR insights through interactive dashboards, helping organizations monitor workforce trends, understand employee attrition, and improve HR planning.

### Skills Demonstrated
Data Cleaning, Data Visualization, KPI Development, Business Intelligence, and HR Data Analysis.
